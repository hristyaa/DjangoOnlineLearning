# Платформа для онлайн-обучения на Django

## Описание:

Веб-приложение для онлайн-обучения на Django, которое представляет LMS-систему, в которой каждый желающий может размещать свои полезные материалы или курсы.

## Установка и настройка:

### Клонируйте репозиторий:

```
https://github.com/hristyaa/DjangoOnlineLearning.git
```

### Создайте виртуальное окружение и установите необходимые зависимости из `pyproject.toml`:

Выполните команду:

```
poetry install
```

Установка конкретных зависимостей (при необходимости):

```
poetry add django 
poetry add dotenv 
poetry add psycopg2
poetry add pillow
poetry add djangorestframework
poetry add django-filter
```

### Настройка базы данных

Скопируйте файл `.env.example` и переименуйте его в `.env`
Откройте `.env` и заполните ваши данные.

## Запуск сервера:

```
python manage.py runserver
```
После запуска сервера приложение будет доступно по адресу: `http://127.0.0.1:8000/`

### Веб-страницы:

- #### Курсы

URL: `http://127.0.0.1:8000/courses`

Для реализации CRUD для курса использованы Viewsets.


- #### Уроки

URL: `http://127.0.0.1:8000/lessons`

Для реализации CRUD для уроков использованы Generic-классы.

- #### Платежи

URL: `http://127.0.0.1:8000/users/payments/`

Реализован эндпоинт вывода списка платежей с возможностями:
менять порядок сортировки по дате оплаты,
фильтровать по курсу или уроку,
фильтровать по способу оплаты.

URL: `http://127.0.0.1:8000/users/payments_create/`

Реализована возможность оплаты курсов через STRIPE. Для создания платежа необходимо отправить запрос с ID курса или урока. Пример POST-запроса:
```
{
    "paid_course": 2
}
```
или
```
{
    "paid_lesson": 3
}
```
Стоимость для оплаты определяется автоматически в соответствии с ценой выбранного курса/урока.

### Возможности для пользователей

Неавторизованные пользователи имеют доступ к авторизации и регистрации. В проекте используется JWT-авторизация. Каждый эндпоинт закрыт авторизацией.

Авторизованные пользователи имеют следующие права по отношению к курсам и урокам:
- просмотр всех курсов и уроков;
- создание курсов и уроков;
- детальный просмотр только своих курсов и уроков;
- редактирование своих курсов и уроков;
- удаление своих курсов и уроков.

Модераторы (группа 'moders') имеют следующие права:
- просмотр всех курсов и уроков;
- детальный просмотр всех курсов и уроков;
- редактирование всех курсов и уроков.

Администраторы имеют полный доступ к работе с пользователями и управлению всеми моделями через админку. Создание администратора осуществляется с помощью кастомной команды:
```
python manage.py csu
```

### Реализованные задачи
- Задача в приложении materials - **send_email_about_update_course** осуществляет асинхронную рассылку писем пользователям, подписанным на курс, об обновлении материалов курса.
- Задача в приложении users - **deactivate_users_by_last_login** с помощью celery-beat реализует деактивацию пользователей, если последний вход был более месяца назад (проверка на таких пользователей проводится 1 раз в день)
